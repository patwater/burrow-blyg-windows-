On friction: every step between the thought and the post is a place the thought can die. It isn't only the minutes lost. Each login screen and each slow preview quietly asks whether the idea is worth the trouble, and most ideas, asked that way, say no. So the tool should disappear.
✦ Contains machine-generated text (claude-opus-5)

The Blygger protocol says a publisher SHOULD disclose generated prose. Today your Worker only discloses text it generated itself. For text generated in this app to be disclosed, the Worker needs one more small endpoint that records "this span was written by model X". That's patch 4, the same size as the others.
