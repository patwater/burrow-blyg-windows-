Lineage in Burrow

Every post can draw on other posts (it forks one, replies to one, or quotes them), and other posts can draw on it. This mock shows that one step in each direction: a small glyph on every post, a view you can walk through, and a ring of actions around the post. It uses only what this Mac already holds, so it works on any blyg. Click inside a window, then use the keys shown.

1 The glyph: which kinds of relation, never how many

Each post in the stream gets a glyph in place of today's "↩". Lines coming in on the left are what the post draws on. Lines going out on the right are what draws on it. Each kind has a fixed slot (fork on top, reply in the middle, quote at the bottom), so the shape carries the meaning as well as the colour. There's never a number: hover for the kinds in words, or click (⌘J) to see who.

2 The lineage view ⌘J: one step each way, and walkable

The post sits in the middle. Above it is what it draws on, below it is what draws on it, and each edge is coloured by relation. Move with the arrow keys; ⏎ on a neighbour makes that post the centre, so you can walk a conversation one step at a time. ⌫ goes back, o opens the selected post in the reader, esc closes.

Responses: what this Mac holds
"What this Mac holds." What a post draws on is exact: it comes from the post itself. What draws on it is everything Burrow has seen: posts in your reading list, your own published posts, and the verified mentions of your posts. A reply from a blyg you don't follow only appears once it mentions one of your posts. The header says so in words, never with a number. verified in code

3 The action ring space: the reader's actions in fixed places

With the centre post selected, space opens the ring. The positions follow the web Studio, so both clients teach the same layout. The bottom puts their words in yours (Reply, Quote), the sides make something of your own (Fork, Link post), and the top only looks (Versions, Open on web). One letter previews an action: a dashed node appears where the result would go, and the panel lists the same four facts for every action. ⏎ does it, and esc backs out.

These actions all exist in Burrow today (stream buttons, ⌘K, ⌘Y, ⌘O). The ring adds a place and a preview, not new behaviour. They're all stock blygger-studio routes, so this doesn't need PR #35. verified in code

4 What it takes to build

  • Data: done, on branch lineage-data. One-step lineage, the fork > reply > quote ranking, partial quotes, and your own posts as responders. verified in code
  • Glyph: a small GPUI canvas drawing per row from the local reference index. It needs a "what does this post draw on" lookup next to the existing "who responds to it". Small. estimate
  • Lineage view and ring: a new sheet with keyboard focus, curved edges and wedge paths drawn on a GPUI canvas, about the size of the versions sheet (⌘Y). estimate
  • Optional later: on a server that has the new upstream GET /api/lineage, also ask it for responses this Mac hasn't seen. Nothing depends on it.
