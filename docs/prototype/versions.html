Versions & pins

One entry per post, and a version history you can browse. That history follows the protocol's promise: only pinned versions are public history. Click the versions.

1 Browsing versions of someone else's post

Only the current version and pinned versions appear. They're browsed from the version pill at the top, so nothing takes up space in the reading view.

Reading › Rue
‹ › step through the versions you're allowed to see, or click the pill for a list. Only the current version and 📌 pinned versions exist here. Unpinned versions don't appear at all.

2 Your own post: full history, and pinning

Your own history is private to you, so you can open every version and restore any of them (restoring publishes as a new version; versions never go backwards). Pinning makes one version public forever.
